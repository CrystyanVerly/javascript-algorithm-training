# 🧠 JavaScript + Logic Training

---

## 🎯 Purpose

This project is designed to develop the ability to solve programming problems independently.

The goal is not simply to write code that works, but to learn how to:

- Understand problems
- Break problems into smaller steps
- Identify patterns
- Choose appropriate data structures
- Implement solutions
- Test edge cases
- Analyze time and space complexity
- Debug reasoning and code
- Optimize solutions
- Recognize algorithmic techniques

---

## 🎯 Final Goal

The ultimate goal of this project is to develop independent problem-solving ability.

Not:

> "I have seen this exact problem before."

But:

> **"I haven't seen this exact problem before, but I know how to start."**

---

## 📚 Learning Path

### Phase 01 — Variables & Operators

Variables, data types, arithmetic operations, comparisons, and basic problem solving.

### Phase 02 — Conditionals

`if`, `else`, logical operators, multiple conditions, and decision-making.

### Phase 03 — Loops

`for`, `while`, counters, accumulators, nested loops, sequences, and repetitive processes.

### Phase 04 — Functions

Parameters, return values, scope, reusable logic, and function composition.

### Phase 05 — Strings

String manipulation, traversal, searching, frequency, transformation, and string problems.

### Phase 06 — Arrays

Array traversal, searching, transformations, aggregation, duplicates, and basic problem solving.

### Phase 07 — Array Methods

`map`, `filter`, `find`, `some`, `every`, `reduce`, and `sort`.

### Phase 08 — Objects

Objects, arrays of objects, data processing, filtering, grouping, and structured data.

### Phase 09 — Counting & Frequency

Frequency counting, duplicates, unique values, grouping, and tracking information while traversing data.

### Phase 10 — Set

Uniqueness, duplicates, intersections, differences, unions, and membership checks.

### Phase 11 — Map

Frequency maps, grouping, indexing, lookups, and efficient data association.

### Phase 12 — Two Pointers

Problems involving two moving positions through arrays or strings.

### Phase 13 — Sliding Window

Fixed and variable windows, subarrays, substrings, and efficient sequential processing.

### Phase 14 — Stack

LIFO structures, parentheses, expressions, history, and monotonic-stack problems.

### Phase 15 — Queue

FIFO structures, task processing, simulations, and queue-based problems.

### Phase 16 — Recursion

Base cases, recursive calls, recursive data processing, and preparation for backtracking.

### Phase 17 — Sorting

Sorting algorithms, custom ordering, merge sort, quick sort, and sorting-based problem solving.

### Phase 18 — Binary Search

Search in sorted data, ranges, rotated arrays, and binary search over an answer space.

### Phase 19 — Complexity & Optimization

Time complexity, space complexity, bottlenecks, optimization, and trade-offs.

### Phase 20 — Linked Lists

Nodes, traversal, insertion, deletion, reversal, cycles, and linked-list problems.

### Phase 21 — Trees

Binary trees, traversals, binary search trees, depth, and breadth-first processing.

### Phase 22 — Heaps & Priority Queues

Heaps, priorities, top-K problems, and priority-based processing.

### Phase 23 — Graphs

Graph representation, DFS, BFS, paths, connectivity, cycles, and shortest paths.

### Phase 24 — Greedy

Local decisions, interval problems, scheduling, and greedy strategies.

### Phase 25 — Backtracking

Subsets, permutations, combinations, constraint-based search, and recursive exploration.

### Phase 26 — Dynamic Programming

Memoization, tabulation, overlapping subproblems, and optimization through previously computed results.

### Phase 27 — Interview Mode

Problems are presented without revealing the intended algorithmic technique.

The objective is to identify the appropriate strategy independently.

### Phase 28 — Final Challenges

Larger problems combining multiple concepts, algorithms, and data structures.
