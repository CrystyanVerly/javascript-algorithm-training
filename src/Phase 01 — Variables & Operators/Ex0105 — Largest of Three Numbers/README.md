# 🧩 Exercise #0105 — Largest of Three Numbers

> **Difficulty:** 🟢 Easy  
> **Phase:** 01 — Variables & Operators  
> **Concepts:** Comparisons · Conditionals · Logical reasoning

---

## 🎯 Problem

Given three numbers, return the largest one.

If two or more numbers are equal and share the largest value, return that value.

## 💻 Function

    function largestOfThree(a, b, c) {
        // ...
    }

## 🧪 Examples

    largestOfThree(10, 5, 8);
    // 10

    largestOfThree(3, 12, 7);
    // 12

    largestOfThree(4, 4, 2);
    // 4

## 📌 Constraints

- `a`, `b`, and `c` are numbers.
- Do not use `Math.max()`.

## 🎯 Goal

Practice combining multiple comparisons and conditional branches.
