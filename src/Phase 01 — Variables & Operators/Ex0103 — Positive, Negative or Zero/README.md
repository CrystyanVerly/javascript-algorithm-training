# 🧩 Exercise #0103 — Positive, Negative or Zero

> **Difficulty:** 🟢 Easy  
> **Phase:** 01 — Fundamentals  
> **Concepts:** Numbers · Comparisons · Conditionals · Functions

---

## 🎯 Problem

Given a number, return `"positive"`, `"negative"`, or `"zero"` according to its value.

## 💻 Function

    function classifyNumber(n) {
        // ...
    }

## 🧪 Examples

    classifyNumber(10);
    // "positive"

    classifyNumber(-5);
    // "negative"

    classifyNumber(0);
    // "zero"

## 📌 Constraints

- `n` is a number.

## 🎯 Goal

Practice comparisons and conditional control flow.
