# 🧩 Exercise #0101 — Greater of Two Numbers

> **Difficulty:** 🟢 Easy  
> **Phase:** 01 — Fundamentals  
> **Concepts:** Variables · Comparisons · Conditionals · Functions

---

## 🎯 Problem

Given two numbers, return the greater one.

If both numbers are equal, return that number.

## 💻 Function

    function greaterNumber(a, b) {
        // ...
    }

## 🧪 Examples

    greaterNumber(10, 5);
    // 10

    greaterNumber(3, 8);
    // 8

    greaterNumber(7, 7);
    // 7

## 📌 Constraints

- `a` and `b` are numbers.
- Do not use `Math.max()`.

## 🎯 Goal

Practice basic comparison and conditional logic.
